# Screens

Screen designs for the ink interface, drawn at the real screen's proportions (59.5 × 67.5 mm, shown at 540 × 612). Each file is one screen.

| File | Screen |
|---|---|
| `Main.dc.html` | Home |
| `Search.dc.html` | Type to search |
| `Messages.dc.html` | Messages |
| `Conversation.dc.html` | Conversation, with the key strip |
| `Call.dc.html` | On a call, with the key strip |
| `Camera.dc.html` | Camera, with the key strip |
| `VoiceNote.dc.html` | Recording a voice note |
| `Create.dc.html` | Home in Create mode (all radios off) |
| `Dialler.dc.html` | Dialler |
| `Contact.dc.html` | A favourite contact |
| `Note.dc.html` | A note with a checklist |
| `Calendar.dc.html` | Agenda |
| `Maps.dc.html` | A curated maps app in focus mode |
| `Settings.dc.html` | Settings |
| `Files.dc.html` | Files: photos, videos, voice notes, microSD |
| `Clock.dc.html` | Clock: alarms, timer, stopwatch |
| `VoiceNotes.dc.html` | Voice notes list, one playing |
| `Contacts.dc.html` | Contacts list with favourites and their light colours |
| `TalkMode.dc.html` | Home in Talk mode (internet off, messaging apps waiting) |
| `Setup1.dc.html` | Setup 1: welcome and language |
| `Setup2.dc.html` | Setup 2: joystick, Back and Menu, with a try-it |
| `Setup.dc.html` | Setup 3: the shape keys and the key strip |
| `Setup4.dc.html` | Setup 4: the silent and connection switches |
| `Setup5.dc.html` | Setup 5: fingerprint on the power button |
| `Setup6.dc.html` | Setup 6: favourites and their light colours |
| `Setup7.dc.html` | Setup 7: mobile, Wi-Fi, account, curated apps, Start |

The files are the sources of the private design canvas (a Design artifact) where they are edited; when a screen changes there, copy it here. They also open directly in a browser as static pages. Names and data in them are made up.

The rules they follow (quiet ink, colour only where functional, the key strip) are in `../SOFTWARE.md`.
